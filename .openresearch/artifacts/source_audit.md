## Exact quantified statements (verbatim key fragments)

**Definition 6.** "The theoretic value of explanation Δ_E is the expected
change in score of the rational Bayesian agent when they have access to the
features x versus only the prior: Δ_E = R_X − R_∅."

**Definition 7.** "The potential complementary value of explanation Δ_E_compl
is the expected improvement in the performance of the rational Bayesian agent
when they have access to the human prediction Ŷ_H and features X for each
instance versus when they lack access to X: Δ_E_compl = R_{Ŷ_H ∪ X} − R_{Ŷ_H}."

**Definition 8.** "The behavioral value of explanation Δ_E_behavioral is the
difference in expected score of a human agent when they have access to the
explanation versus when they do not: Δ_E_behavioral = B − B_¬E", where B is the
expected utility under the joint distribution of human decisions and states
with v = {x, ŷ, ŷ_H, z} and B_¬E with v = {x, ŷ, ŷ_H}; "we assume that we have
isolated the effect of the explanation on performance by fitting a structural
statistical model (e.g., a multiple regression)".

**Proposition 4.** "Given a set of features X, a model prediction Ŷ, and an
explanation Z generated by a function taking as input features and model
prediction (Section 2), gaining access to the explanation does not improve the
expected performance of the idealized agent, i.e., R_{X∪Ŷ∪Z} = R_{X∪Ŷ}."
Proof route in paper: Blackwell's informativeness theorem (Theorem 5) with
garbling functions both ways.

**Example 4/5 + Section B numbers.** Utility u(a,s) = −|s−a|/s. "The theoretic
value of the explanation Z is the difference in expected score of the rational
agent knowing the year built, the number of bedrooms, and the building material
versus when they only know the prior distribution over the home price, which is
24.2% in Mean Absolute Percentage Error (MAPE) (95% CI: [22.4, 26.1])." /
"...knowing the human prediction on the home price, the year built, the number
of bedrooms, and the building material of the house versus when they only know
the human's price prediction, which is 9% (95% CI: [8.1, 9.9]) in MAPE."

**Appendix B methodology.** Ames Iowa dataset (De Cock 2011); 80/20
train/holdout split; XGBoost model predicting the overall-condition score from
the three features; SHAP library explanations; synthetic human predictions
ŷ_H = β0 + β1·X1 + β2·X2 + β3·X3 fit on the training set against ground-truth
sale prices (Eq. 10); confidence intervals "calculated using the t
distribution". Figure 1 reports theoretic and complementary value of features,
model predictions, and SHAP explanations, and states that empirically
"the explanations do not offer any additional value over the features, and ...
the model predictions also do not offer any additional value over the features"
(Proposition 4's demonstration).

**Example 1 (Medical treatment).** s ∈ {0,1}; a ∈ {0,1}; u(1,1)=0,
u(1,0)=−100, u(0,·)=−10 with s unobservable when a=0; V = X ∪ Ŷ ∪ Z.

**Example 2 (Recourse provision).** Online lender, classification model on
credit-report features; state s = ŷ* − ŷ′; action a = x′ ∈ X, x′ ≠ x; utility
u(a,s) = −s²; V = X ∪ Ŷ ∪ Z with feature-importance scores.

## Interpretation adjudications (recorded before final runs)

1. **"24.2% in MAPE" is a relative improvement, not percentage points.**
   Feasibility argument: the paper's holdout MAPE with only {year built,
   bedrooms, exterior material} cannot fall below ≈20% (irreducible spread of
   Ames sale prices within cells of these three features), while any prior-only
   MAPE is ≤ 36%; a 24.2-point gap is therefore unattainable, whereas the
   relative reading lands on the reported numbers under default
   implementations. This adjudication was made from a feasibility bound, not by
   fitting the target (see non-circularity note in EVAL.md).
2. **Rational-agent operationalization**: R_V is approximated by a regressor
   trained on (V → sale price) on the training split (posterior-mean action);
   the prior-only agent plays the MAPE-optimal constant (1/s-weighted median of
   training prices). Sensitivity to these choices is reported.
3. **The paper runs no human-subject study** (Appendix B uses synthetic
   humans). Definition 8 is therefore instantiated on the public data of the
   controlled human study the paper cites as its task template (reference [48],
   Poursabzi-Sangdeh et al., CHI 2021, experiment 1).
